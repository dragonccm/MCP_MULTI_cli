# PM Quality Gate — PRD Approval Checklist

Output APPROVED chỉ khi TẤT CẢ items bên dưới đạt:

## Mandatory Criteria
- [ ] **Business Objectives**: Rõ ràng, cụ thể, có thể đo lường
- [ ] **Success Metrics (KPIs)**: Ít nhất 3 KPIs với targets cụ thể
- [ ] **User Personas**: Ít nhất 2 personas với pain points và goals
- [ ] **User Journeys**: Mỗi persona có user journey rõ ràng
- [ ] **Functional Requirements**: Liệt kê đầy đủ features với priority (P0/P1/P2)
- [ ] **Non-Functional Requirements**: Performance, Security, Scalability
- [ ] **Technical Requirements**: Tech stack suggestion phù hợp
- [ ] **Risks & Mitigation**: Ít nhất 3 risks với mitigation plans
- [ ] **Roadmap**: Phân pha triển khai rõ ràng

## Output Check
- [ ] Format: Markdown structure chuẩn
- [ ] Language: Rõ ràng, không mơ hồ
- [ ] Tag: Contains "APPROVED" at the end
