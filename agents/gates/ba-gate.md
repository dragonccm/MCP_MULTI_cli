# BA Quality Gate — Stories Approval Checklist

Output APPROVED chỉ khi TẤT CẢ items bên dưới đạt:

## Mandatory Criteria
- [ ] **Epic Coverage**: Mỗi feature trong PRD đều có epic tương ứng
- [ ] **User Stories**: Format chuẩn "As a/I want/So that"
- [ ] **Acceptance Criteria**: Mỗi story có ≥2 acceptance criteria (Given/When/Then)
- [ ] **Edge Cases**: Ít nhất 2 edge cases per story
- [ ] **Story Points**: Estimated cho tất cả stories
- [ ] **Data Models**: Đầy đủ entities, fields, types, constraints
- [ ] **Relationships**: ERD rõ ràng giữa các entities
- [ ] **API Specifications**: Endpoints, methods, request/response schemas
- [ ] **UI Descriptions**: Layout + components cho mỗi screen chính

## Output Check
- [ ] No conflicting requirements
- [ ] Stories independent (INVEST criteria)
- [ ] Tag: Contains "APPROVED" at the end
